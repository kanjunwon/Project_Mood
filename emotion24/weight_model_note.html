EMOTION24 · WEIGHT MODEL NOTE

퍼스널 검사 기반 감정 가중치 알고리즘 — 설계 노트

emotion24-bert가 뽑는 24개 감정 확률에, 퍼스널 검사(HSP·LOT-R) 점수로 개인화된 가중치를 얹는 실험. 그룹 단위 모델의 한계를 발견하고 연속값 각성도 모델로 보완한 과정을 정리한다.

실험 위치: emotion24/weight_test.py 채택 모델: 3(연속값 각성도) alpha = 0.4

1. 배경

사용자가 프론트에서 답하는 퍼스널 감정 검사(HSP 13문항·LOT-R 6문항)의 응답을 바탕으로, 일기 감정 분석 결과(24개 감정 중 확률 상위 top-3)에 그 사람의 성향을 반영한 가중치를 주고 싶다는 아이디어에서 출발했다. 백엔드의 weight_profile 필드는 아직 계산 로직이 없는 TODO 상태라, 알고리즘 자체를 먼저 독립적으로 실험한 뒤 방향을 정하는 단계다.

2. 두 모델과 채택 이유

그룹 단위로만 가중치를 주면 그룹 안에서는 절대 순서가 안 바뀐다는 구조적 한계를 발견하고, 각성도를 연속값으로 세분화해 해결했다.

왜 1축이 아니라 3번인가

  1. 이 프로젝트가 원하는 건 "같은 부정적인 상황도 사람 성향에 따라 다르게 반영되는 것"이다 — 예를 들어 화가 났을 때, 민감한 사람은 순수한 분노(화나는) 쪽으로, 덜 민감한 사람은 짜증 쪽으로 더 기울 수 있다는 걸 표현하고 싶었다.
  2. 1축은 "부정 그룹 전체"에만 배수를 곱하기 때문에, 그룹 안에 있는 화나는·짜증나는·실망한이 항상 같은 비율로만 움직인다 — 개인화를 표방해도 그룹 내부에서는 사실상 개인화가 전혀 일어나지 않는다.
  3. 이건 alpha를 아무리 올려도 못 고치는 수식 구조 자체의 한계다 (아래 표 참고) — 파라미터 튜닝 문제가 아니라 모델을 바꿔야만 풀리는 문제였다.
  4. 3번(연속값 각성도)은 24개 감정 각각에 고유한 값을 줘서, 같은 그룹 안에서도 서로 다르게, 심지어 반대로 움직이게 만든다 — 화나는(0.95)과 짜증나는(0.80)의 반응 폭이 달라져서 처음 목표였던 "성향별로 다르게 반응하는 감정 분석"에 실제로 부합한다.

1축은 alpha를 최대(1.0)로, 페르소나를 극단으로 줘도 이 비율이 소수점 6자리까지 완전히 고정된다 — 같은 그룹(같은 배수)을 받는 두 감정은 renormalize를 거쳐도 서로 간의 비율이 수학적으로 절대 변할 수 없기 때문이다. 3(채택) 모델은 같은 조건에서 비율이 5.6~12.1까지 실제로 움직인다. 즉 1축으로는 "화나는과 짜증나는의 비중 조정"이 alpha 값과 무관하게 원천적으로 불가능하고, 3번 모델만이 구조적으로 이를 가능하게 한다.

3. 계산 공식 — 4단계

worked example: HSP:LOT-R = 7:3 → hsp_score=0.7, lotr_score=0.3, alpha=0.4

1

LOT-R → 정서가(긍정/부정) 배수

valence_pos = 1 + alpha×(lotr_score−0.5)×2 valence_neg = 2 − valence_pos

0.7 / 0.3 대입 → valence_neg = 1.16 (부정 그룹 전체의 출발 배수)

2

HSP → 각성도 "기울기"

hsp_tilt = alpha×(hsp_score−0.5)×2

→ hsp_tilt = 0.16 — 각성도가 결과에 얼마나 세게 반영될지를 정하는 크기

3

감정별 각성도 값을 기울기에 반영

arousal_mult(감정) = 1 + hsp_tilt×(그 감정의 각성도−0.5)×2
감정각성도arousal_mult
화나는0.951.144
짜증나는0.801.096
실망한0.450.984
4

정서가 × 각성도 = 최종 배수, 곱한 뒤 renormalize

최종 배수 = valence_neg × arousal_mult
감정최종 배수원래 확률최종 결과

6. 한계 및 참고

EMOTION_AROUSAL_LEVEL의 소수점 수치는 여전히 가설값이지만, 순서의 방향성은 실제 논문으로 부분 검증됨.

박인조·민경환(2005), 「한국어 감정단어의 목록 작성과 차원 탐색」(한국심리학회지: 사회 및 성격, 19(1), 109-129)의 부록에는 434개 한국어 감정단어의 실측 활성화(각성도) 값이 7점 척도로 실려 있다. 본문에서 명시적으로 확인된 것: 활성화 최저값 = 1.90(안락하다), 최고값 = 6.66(열광)이며, 최저 그룹은 안락하다·안도하다·평안하다·무력감, 최고 그룹은 경악하다·성나다·분노하다·열광이다 — "분노 계열이 최고, 편안함 계열이 최저"라는 우리 순서의 방향성과 일치한다. 다만 24개 단어 각각의 정확한 소수점 값까지는 부록 표(OCR 정렬 문제로 행 대응을 확신할 수 없어) 대조하지 못했으니, 정확한 개별 수치가 필요하면 논문 원문 부록 1(16~19쪽)을 직접 확인할 것.

HSP/LOT-R 원점수 → 0~1 정규화는 compute_persona_scores()에서 문항 수 차이(13개 vs 6개)를 평균으로 상쇄하도록 처리되어 있다.
